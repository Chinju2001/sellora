# 🛍️ Sellora

**Sellora** is a full-stack hyperlocal marketplace web application built using the MERN stack. It allows users to discover, list, and manage products within their local community.

## ✨ Features

* 🔐 User Authentication
* 📦 Product Listings
* 🔎 Product Search
* 🗂️ Category Filtering
* 📄 Product Details
* 👤 User Profile
* ➕ Add Products
* ✏️ Edit Products
* 🗑️ Delete Products
* 📱 Responsive Design

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* React Router
* CSS

### Backend

* Node.js
* Express.js
* REST APIs

### Database

* MongoDB

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Chinju2001/sellora.git
cd sellora
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
```

### 3. Install backend dependencies

```bash
cd ../backend
npm install
```

### 4. Run the frontend

```bash
npm run dev
```

### 5. Run the backend

```bash
npm start
```
