# 🛍️ Sellora

Sellora is a full-stack hyperlocal marketplace web application built with the MERN stack. It allows users to discover, list, manage, and interact with products within their local community.

## 🌐 Live Demo

https://sellora-rdyl.onrender.com

## ✨ Features

- 🔐 User registration and login
- 📦 Create, edit, and delete product listings
- 🔎 Product search
- 🗂️ Category filtering
- 📄 Product details
- 👤 User profiles
- ❤️ Wishlist
- 💬 User-to-user chat
- ⭐ Seller ratings
- 🚩 Product reporting
- 🛡️ Admin dashboard
- 🖼️ Cloudinary image uploads
- 📱 Responsive design

## ⚙️ Installation

### 1. Clone the repository

    git clone https://github.com/Chinju2001/sellora.git
    cd sellora

### 2. Install frontend dependencies

    cd frontend
    npm install

### 3. Install backend dependencies

    cd ../backend
    npm install

### 4. Configure environment variables

Create the required `.env` files.

Frontend:

    VITE_API_URL=your_backend_url

Backend requires MongoDB, JWT, and Cloudinary environment variables.

### 5. Run the frontend

    cd frontend
    npm run dev

### 6. Run the backend

    cd ../backend
    npm start

## 🚀 Deployment

- Frontend: Render Static Site
- Backend: Render Web Service
- Database: MongoDB Atlas
- Image Storage: Cloudinary
