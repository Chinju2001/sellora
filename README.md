# 🛍️ LocoMarket

LocoMarket is a modern hyperlocal marketplace built using the MERN stack. It allows users to buy and sell products within their local community.

The goal of this project is to build a clean, responsive, and scalable marketplace application while learning full-stack web development.

---

## 🚀 Features

- User Authentication
- Product Listings
- Search Products
- Category Filtering
- Product Details
- User Profile
- Add/Edit/Delete Products
- Responsive Design
- Modern UI

---

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Chinju2001/locomarket.git
```

Install frontend dependencies

```bash
cd frontend
npm install
```

Install backend dependencies

```bash
cd ../backend
npm install
```

Run the frontend

```bash
npm run dev
```

Run the backend

```bash
npm start
```
